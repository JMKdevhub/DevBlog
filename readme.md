# ✍️ DevBlog

A modern blog application built with **React** and **Appwrite**.

> 🚧 This project is currently under development and will be continuously improved as new features are added.

## 🚀 Features

* 🔐 User Authentication (Login / Signup)
* 📝 Create, Edit & Delete Posts
* 🖼️ Featured Image Uploads
* 📖 Rich Text Editor
* 🛡️ Protected Routes
* 🗃️ Appwrite Database & Storage
* ⚡ React Router
* 🔄 Redux Toolkit for State Management
* 📱 Responsive UI

## 🛠️ Tech Stack

* **React + Vite**
* **Tailwind CSS**
* **React Router**
* **Redux Toolkit**
* **React Hook Form**
* **TinyMCE**
* **Appwrite**

## ⚙️ Setup

```bash
git clone <your-repository-url>
cd <project-folder>
npm install
npm run dev
```

Create a `.env` file and add your Appwrite configuration:

```env
VITE_APPWRITE_URL=
VITE_APPWRITE_PROJECT_ID=
VITE_APPWRITE_DATABASE_ID=
VITE_APPWRITE_TABLE_ID=
VITE_APPWRITE_BUCKET_ID=
```
